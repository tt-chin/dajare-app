# PRODUCT.md — Specification Freeze v1
## Concept
6–12歳の子どもがダジャレを作り、AI判定・スコア・短い説明・キャラクター反応を楽しむ日本語言葉遊びアプリ。初期UX中心は小学1～4年生。**親子で笑って、ことばを学ぶ。**

## Core
`Home → Input → AI判定 → Result → もういっかい`
V1 adds `今日のお題 → Hint` and `ダジャレ図鑑`.

## Frozen screens
Home / Dajare Input / Result / Daily Topic / Collection.

## MVP
P0: text input, Functions/Gemini judging, 0–100 score, explanation, reaction, loading/error/safety.
P1: daily topic, one-step hint, collection/persistence.
P2: Japanese speech after core stability.

## Score
0–39 さむ～い！🥶 / 40–69 いいね！😆 / 70–89 うまい！🤣 / 90–99 天才！🤩 / 100 伝説のダジャレ王！👑.
Low score is playful feedback, never child ability evaluation.

## Out
Public ranking/friends/posts/chat/social/photo upload/complex economy/parent-child battle are not MVP.
