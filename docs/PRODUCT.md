# PRODUCT.md — 規格凍結 v1
## 概念
6–12歳の子どもがダジャレを作り、AI判定・スコア・短い説明・キャラクター反応を楽しむ日本語言葉遊びアプリ。初期UX中心は小学1～4年生。**親子で笑って、ことばを学ぶ。**

（中文翻譯：讓 6–12 歲兒童創作ダジャレ，享受 AI 判定、分數、簡短說明與角色反應的日文文字遊戲 app。初期 UX 以小學 1～4 年級為中心。**親子一起笑，一起學習語言。**）

## 核心流程
`Home → Input → AI判定 → Result → もういっかい`
V1 另外加入 `今日のお題 → Hint` 與 `ダジャレ図鑑`。

## 凍結的畫面
Home / Dajare Input / Result / Daily Topic / Collection。

## MVP
P0：文字輸入、Functions/Gemini 判定、0–100 分數、說明、反應、載入中/錯誤/安全處理。
P1：每日題目、一步提示、図鑑/資料保存。
P2：核心功能穩定後，加入日文語音輸入。

## 分數
0–39 さむ～い！🥶 / 40–69 いいね！😆 / 70–89 うまい！🤣 / 90–99 天才！🤩 / 100 伝説のダジャレ王！👑。
低分是好玩的回饋，不得作為對兒童能力的評價。
